# Problem

As a nail technician, when I attempt to expand my collection of products like nail polishes, I often experience an issue of trying to remember what I already have in my collection. If I could keep track of the colors in my collection, I would be able to avoid purchasing duplicate colors and save money.

# Initial requirements

- R1: The program must be able to add a polish with its details (brand, color name, finish, and how many bottles are currently in stock).
- R2: The program must display the whole collection at once.
- R3: The program must let me search through the collection by brand, color name, or finish.
- R4: The program must give me the option to sort by oldest to newest added or by quantity in stock, and to filter by finish.
- R5: The program must prevent me from adding a polish if the brand and color name already exist, not one or the other because some polishes may have the same name but are from different brands.
- R6: If I try to add a polish that already exists, I should be able to see its quantity and update it in case there is no more in stock and I am replenishing the inventory.
